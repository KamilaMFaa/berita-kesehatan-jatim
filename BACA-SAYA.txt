LANGKAH PEMASANGAN (±3 menit)
-----------------------------
1. Ekstrak ZIP ini.
2. Buka folder lokal repo GitHub Anda (yang berisi package.json).
3. Salin folder "src" dari folder "perbaikan-situs" ke root repo,
   TIMPA file/folder lama bila ditanya. Struktur file yang tersalin:
     src/lib/db.ts                              (ganti)
     src/lib/berita-json.ts                     (baru)
     src/app/api/articles/route.ts              (ganti)
     src/app/api/articles/aggregate/route.ts    (ganti)
     src/app/api/chat/route.ts                  (ganti)
     src/app/api/env-check/route.ts             (baru)
4. CEK prisma/schema.prisma Anda — pastikan blok generator memuat
   previewFeatures = ["driverAdapters"] :

     generator client {
       provider        = "prisma-client-js"
       previewFeatures = ["driverAdapters"]
     }

   Bila belum ada, tambahkan baris previewFeatures (lihat contoh
   schema-generator-block.txt).
5. Pastikan package.json memuat dependensi ini (seharusnya sudah ada
   dari perbaikan sebelumnya — bila belum, tambahkan versi persis):
     "@libsql/client": "0.18.0"
     "@prisma/adapter-libsql": "6.19.2"
     "@prisma/client": "6.19.2"
     "prisma": "6.19.2"
6. Commit + push ke branch main:
     git add -A
     git commit -m "Perbaikan: db.ts dual-mode Turso + fallback JSON"
     git push
7. Tunggu deployment Vercel selesai (status Ready, ±1-2 menit).
